Contribute & report a problem

Help improve E-Bike Companion by submitting careful bug reports and compatibility observations.

Public submissions need a working endpoint. The app repository is private, so its GitHub issue form is not a public community form. This page explains what to submit safely; a public form provider or separate public repository must be configured before accepting submissions here.

Bug report checklist

  • App version/build and Android version
  • Bike model/year, display and controller (if known)
  • What you expected and what happened
  • Steps to reproduce and relevant error text

Compatibility evidence

  • Exact hardware and firmware details when known
  • Whether the result was repeated
  • Which fields were observed versus inferred
  • Limitations and what was not tested

Protect your privacy

  • Do not submit GPS routes, home/work locations, personal contact details, serial numbers, tokens or unredacted screenshots.
  • Inspect diagnostic exports before sharing. Sanitisation reduces risk but is not a guarantee that every identifier is removed.
  • Only share information you have permission to disclose.
  • Never perform testing while riding or send control commands to a bike as part of an unverified experiment.

How to submit publicly

A public submission route has not been connected yet. Until it is, use the support page for guidance and do not assume this static page sends data anywhere.
