USER GUIDE / SETTINGS

Settings

Understand language, Android permissions and app configuration.

Language

Choose a language from the options available in your installed app version. Some technical names, controller-reported values or newly introduced screens may remain in English while translations are being completed. Report missing or misleading translations with the screen name and app version.

Android permissions

Permission requirements depend on Android version and the features you use. Review app permissions in Android Settings. Grant only permissions needed for the feature you intend to use, and consult the privacy page for the project's stated data practices.

Version and support information

When asking for help, include the app version/build and Android version. If a setting appears unavailable, it may depend on the installed release or connected hardware.
