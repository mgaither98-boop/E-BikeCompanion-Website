Home dashboard

A guide to reading the information shown by the app.

Read the status first

Use the dashboard to understand whether the app is connected and which information is currently available. Status indicators may differ by app version, bike, display and connected driver.

  • Connection status: a connected state means the app has an active connection; it does not guarantee every data field is supported.
  • Battery and trip information: values are shown only when the connected bike/driver provides data the app can interpret. Treat missing or unavailable values as unknown rather than zero.
  • Assist, PAS and throttle indicators: these describe information reported or interpreted by the current connection. Their presence does not mean the app can safely or reliably change that setting.
  • Offline indicator: internet access and Bluetooth access are separate. Some local features may work offline, while online resources may not.

Quick checks when a value looks wrong

  1. Confirm that the app is connected to the intended device.
  2. Compare the value with the bike's own display while stationary.
  3. Reconnect once if the data appears stale.
  4. Note the app version, bike model and exact field when reporting a discrepancy.

Do not use an app reading as the sole basis for a safety-critical decision.
