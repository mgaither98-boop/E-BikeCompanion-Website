Offline maps

Prepare supported raster MBTiles and test map coverage before you head out.

Understand the files

An MBTiles file is a container for map tiles. E-Bike Companion's offline map support expects a compatible raster tile source. A GPX file stores route or track data; it does not contain the map imagery beneath that route.

Prepare an offline map

  1. Choose a raster MBTiles file from a source whose licence permits your intended use.
  2. Check that the file has completed downloading and that your phone has enough free storage.
  3. Open the app's map/offline-map area and use the import or download action available in your installed version.
  4. Wait for the operation to finish; large regional files can take time to copy or index.
  5. Before travelling, enable airplane mode or otherwise disconnect internet access and inspect the exact area and zoom levels you expect to need.

Some map detail is missing offline

  1. Confirm the map file covers the location you are viewing.
  2. Check that the file includes the zoom level you need. A regional file may not contain detailed tiles at every zoom.
  3. Move to the downloaded area and test multiple zoom levels while still offline.
  4. If details appear only when back online, the requested tiles may not have been included locally.
  5. If the app provides a delete/import option, re-import a known-good file and repeat the offline test.

Routes and GPS

Import and inspect a GPX route separately from the map tiles. Confirm that the route is in the expected location before setting off. GPS accuracy can vary with phone placement, buildings, tree cover and satellite reception.

Before every ride: Verify offline coverage in advance and keep a safe backup for navigation. Do not interact with the phone while riding.
