Ride profiles

Understand saved profiles and verify what your current bike setup actually supports.

What a profile means

Ride profiles can help organise settings supported by the installed app build. The exact fields, save behaviour and whether a value can be applied depend on the feature and connected hardware. A saved profile is not proof that the bike accepted every setting.

Safe profile workflow

  1. Stop in a safe place and keep the bike stationary.
  2. Open the profile area and review the profile name and fields before changing anything.
  3. Save or rename profiles only using controls provided by the installed version.
  4. If the app offers a read-back or confirmation state, check it after applying a supported setting.
  5. Compare results with the bike's own display or official documentation before riding.

If a profile does not behave as expected

  • Check whether the bike/controller is listed as verified for that capability.
  • Reconnect and inspect the reported status while stationary.
  • Do not assume that a preset applies identically across different controllers.
  • Report the app version, bike model, controller/display and the specific field that failed.
Important: This guide does not recommend increasing speed limits, bypassing manufacturer restrictions or changing firmware. Experimental or unverified controls should not be used on a moving bike.
