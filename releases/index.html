VERSION 0.9.0 · BUILD 50 · 2026-10-24

MapLibre ride map and GPS tracking

A redesigned ride map brings GPS tracking and offline-map tools into one cleaner experience.

Changes

  • Opens the new MapLibre ride map directly from Rider Hub's Offline maps and routes entry.
  • Shows live GPS position and route line with ride time, distance and GPS speed.
  • Adds start, pause, resume, stop-and-save ride controls using the existing local ride service.
  • Reuses saved ride history and routes, with ride data retained on the phone.
  • Keeps offline region downloads and raster MBTiles import available in the new map experience.

Known limitations

  • GPS ride tracking has been tested online; verify a complete ride with Wi-Fi and mobile data disabled before relying on it offline.
  • Offline route following uses imported GPX tracks or previous rides; arbitrary turn-by-turn route calculation is not included.

GPS and saved ride data remain on the phone. No new bike command or controller protocol write was added.

VERSION 0.7.3 · BUILD 39 · 2026-10-23

Fast offline maps

Raster MBTiles imports now remain as one database file for faster, more storage-efficient offline maps.

Changes

  • Streams MBTiles into private app storage with real copy progress and cancellation.
  • Validates the MBTiles schema and raster format before finalising an import.
  • Reads visible tiles directly from SQLite, supports TMS and XYZ row schemes, and uses a bounded compressed-tile cache.
  • Shows map storage mode, file size, tile count, image format and zoom range.
  • Cleans up interrupted partial imports on startup.

Known limitations

  • Offline map viewing supports raster MBTiles; it does not calculate arbitrary offline turn-by-turn routes.
  • Compatibility claims depend on exact hardware and reviewed test evidence.

No new bike command was added and no controller protocol or safety policy changed.

Before installing an update

  • Back up any data you want to keep, where the app provides an export option.
  • Read the release notes and known issues.
  • Review new permissions or changed sharing behaviour.
  • Install updates from the official store once available.
